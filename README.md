# Fun stuff

Small things I built for fun, free to copy and change.

| What | In one line | Folder |
|---|---|---|
| Movie Night | A page for two people to choose what to watch. It deals one pick for tonight and keeps a To watch list and a Seen list. | [`movie-night/`](movie-night/README.md) |
| Couch Kart | An original two-player kart racer, built as a Super Nintendo game. The source, the tools and the game file are here. | [`couch-kart/`](couch-kart/README.md) |

Each folder has its own README with how to try it and how to make it yours with Claude. Pictures and a demo are on the site: https://danielercohen.github.io/ai-pm/personal/

The tools I use for product work are in their own repositories, listed on https://danielercohen.github.io/ai-pm/toolkit/
